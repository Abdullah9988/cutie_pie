# For Huma Gudey

A static, GitHub Pages-ready love-letter site. It has no build step.

## Publish on GitHub Pages

1. Create a GitHub repository and upload these files to its root.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and the `/(root)` folder, then save.
4. GitHub will show the public link after it deploys.

## Personalize the letter

Open `index.html` and replace the four paragraphs inside `<article class="letter">` with your own words. The rest of the page is ready to use.
